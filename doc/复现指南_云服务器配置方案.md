# UrbanGPT 论文复现完整指南（云服务器版）

根据代码仓库 [UrbanGPT](https://github.com/HKUDS/UrbanGPT) 和论文，以下是完整的云服务器复现方案。

---

## 1. 云服务器硬件配置建议

| 组件 | 最低配置 | 推荐配置 |
|------|----------|----------|
| **GPU** | 4× A100 (40GB) | 8× A100 (80GB) |
| **CPU** | 32 核 | 64 核 |
| **内存** | 128 GB | 256 GB |
| **存储** | 200 GB SSD | 500 GB SSD |
| **CUDA** | 11.7 | 11.7 |

> ⚠️ **说明**：训练脚本默认使用 `--nproc_per_node=8`（8 卡分布式训练），基于 Vicuna-7B-v1.5-16k。如果只有 4 卡，可将该参数改为 4，但需要相应调整 `per_device_train_batch_size` 和 `gradient_accumulation_steps`。

## 3. 下载预训练模型和数据

```bash
cd UrbanGPT

# ==================== 3.1 下载 Vicuna-7B-v1.5-16k 基座模型 ====================
# 方法 A：通过 HuggingFace 下载
huggingface-cli download lmsys/vicuna-7b-v1.5-16k --local-dir ./checkpoints/vicuna-7b-v1.5-16k

# 方法 B：若网络受限，使用镜像
# export HF_ENDPOINT=https://hf-mirror.com
# huggingface-cli download lmsys/vicuna-7b-v1.5-16k --local-dir ./checkpoints/vicuna-7b-v1.5-16k

# ⚠️ 重要：替换 config.json
# 需要使用 UrbanGPT 提供的 config.json
# 下载并覆盖: https://huggingface.co/datasets/bjdwh/checkpoints/blob/main/train_config/config.json
wget -O ./checkpoints/vicuna-7b-v1.5-16k/config.json \
    https://huggingface.co/datasets/bjdwh/checkpoints/resolve/main/train_config/config.json

# ==================== 3.2 时空编码器预训练权重（仓库内已包含）====================
# 确认存在: ./checkpoints/st_encoder/pretrain_stencoder.pth
ls -lh ./checkpoints/st_encoder/pretrain_stencoder.pth

# ==================== 3.3 下载训练数据 ====================
# 从 HuggingFace 下载指令训练数据
huggingface-cli download bjdwh/ST_data_urbangpt --local-dir ./ST_data_urbangpt --include "train_data/*"
# 或使用 git lfs:
# git clone https://huggingface.co/datasets/bjdwh/ST_data_urbangpt

# 数据目录结构应为：
# ./ST_data_urbangpt/train_data/
#   ├── multi_NYC.json          # 指令数据
#   └── multi_NYC_pkl.pkl       # 时空特征数据
```

## 4. 开始训练

```bash
cd UrbanGPT

# 设置环境变量
export CUDA_VISIBLE_DEVICES=0,1,2,3,4,5,6,7
export WANDB_MODE=offline  # 若不想登录 wandb

# ==================== 一键训练（8× A100） ====================
# 若只需 4 卡，修改 --nproc_per_node=4，并调整 batch_size 和 gradient_accumulation_steps

bash urbangpt_train.sh
```

训练脚本 `urbangpt_train.sh` 核心内容：

```bash
#!/bin/bash
model_path=./checkpoints/vicuna-7b-v1.5-16k
instruct_ds=./ST_data_urbangpt/train_data/multi_NYC.json
st_data_path=./ST_data_urbangpt/train_data/multi_NYC_pkl.pkl
pretra_ste=ST_Encoder
output_model=./checkpoints/UrbanGPT

wandb offline
python -m torch.distributed.run --nnodes=1 --nproc_per_node=8 --master_port=20001 \
    urbangpt/train/train_mem.py \
    --model_name_or_path ${model_path} \
    --version v1 \
    --data_path ${instruct_ds} \
    --st_content ./TAXI.json \
    --st_data_path ${st_data_path} \
    --st_tower ${pretra_ste} \
    --tune_st_mlp_adapter True \
    --st_select_layer -2 \
    --use_st_start_end \
    --bf16 True \
    --output_dir ${output_model} \
    --num_train_epochs 3 \
    --per_device_train_batch_size 4 \
    --per_device_eval_batch_size 4 \
    --gradient_accumulation_steps 1 \
    --evaluation_strategy "no" \
    --save_strategy "steps" \
    --save_steps 2400 \
    --save_total_limit 1 \
    --learning_rate 2e-3 \
    --weight_decay 0. \
    --warmup_ratio 0.03 \
    --lr_scheduler_type "cosine" \
    --logging_steps 1 \
    --tf32 True \
    --model_max_length 2048 \
    --gradient_checkpointing True \
    --lazy_preprocess True \
    --report_to wandb
```

### 关键训练参数说明

| 参数 | 含义 | 说明 |
|------|------|------|
| `--nproc_per_node=8` | 使用 8 GPU | 不足 8 卡则改小 |
| `--bf16` | BF16 混合精度 | A100 必须开启，节省显存 |
| `--per_device_train_batch_size=4` | 每卡 batch=4 | 8 卡有效 batch=32 |
| `--learning_rate=2e-3` | 学习率 | 论文设定，仅训练 ST adapter + 预测头 |
| `--tune_st_mlp_adapter=True` | 仅训练 ST adapter | LLM 主体冻结 |
| `--gradient_checkpointing` | 梯度检查点 | 节省显存 |
| `--model_max_length=2048` | 最大序列长度 | Vicuna-16k 截断到 2048 |

## 7. 常见问题与注意事项

| 问题 | 解决方案 |
|------|----------|
| **flash-attn 安装失败** | 确保是 `flash_attn-2.3.5+cu117torch2.0` 版本，严格匹配 CUDA 11.7 |
| **transformers 版本冲突** | flash-attn 2.3.5 必须搭配 `transformers==4.34.0` |
| **显存不足 (OOM)** | ① 减小 `per_device_train_batch_size` ② 增大 `gradient_accumulation_steps` ③ 启用 LoRA (`--lora_enable True`) |
| **Vicuna config.json 不匹配** | 必须用 UrbanGPT 提供的 config.json 替换原版 |
| **时空编码器加载失败** | 确认 `pretrain_stencoder.pth` 在 `checkpoints/st_encoder/` 下 |
| **HuggingFace 下载慢** | 设置 `export HF_ENDPOINT=https://hf-mirror.com` 使用镜像 |

## 9. 模型架构概览

UrbanGPT 的核心架构由以下三部分组成：

1. **基座 LLM**：基于 Vicuna-7B-v1.5-16k，负责语言理解和生成
2. **时空编码器 (ST-Encoder)**：基于 TCN（时间卷积网络）和扩张卷积（Dilated Inception），将时空序列数据编码为 LLM 可理解的表示
3. **ST-Adapter（投影层 + 预测头）**：
   - `st_projector`：将时空编码器的输出投影到 LLM 的隐空间
   - `st_pred_linear_1/2/3`：用于回归和分类任务的预测头

训练时**仅微调 ST-Adapter 和预测头**，LLM 主体和时空编码器冻结。
